# Alfredo's Cheat-Sheets

> Quick references for the tools I use every day in DevSecOps and my homelab.

## About

I'm Alfredo. I write educational tech content for DevSecOps professionals and homelab enthusiasts. This repository is where my day-to-day notes live, so I can find them quickly and share them with anyone who finds them useful.

## What's Inside

| Type | Description |
| --- | --- |
| 🧩 **Snippets** | Short, reusable pieces of code and configuration |
| 📘 **Docs** | Technical notes explaining how things work and why |
| ⌨️ **Commands** | Handy command lists for the CLI tools I rely on |

## How to Use These Notes

Browse the folders, copy what you need, and adapt it to your own environment. Everything here is free to use. Always test in a safe environment before running anything in production.

## Keep in Mind

Tools and platforms change quickly, so some notes may lag behind the latest releases. I update them as often as I can, but I can't promise they're always current. If something looks outdated, please let me know.
