# Security Policy

I take the security of my projects seriously. If you discover a vulnerability or have concerns about the security practices recommended in this repository, please let me know right away. I appreciate responsible disclosure and will do my best to address every report promptly.

## Reporting a Vulnerability

To report a vulnerability, please follow these steps:

1. Open the **Security** tab of this repository on GitHub.
2. Click **"Report a vulnerability"**.
3. Describe the vulnerability and its potential impact in as much detail as you can.
4. If possible, include steps to reproduce the issue or a proof of concept (PoC).
5. Submit the report.

Once I receive the private report, I will promptly investigate and assess the issue.

Please do not disclose the vulnerability publicly (in repositories, issue trackers, forums, or elsewhere) until I've had a chance to review it and release a fix.

## Scope

This policy covers all code and files in this repository, as well as any dependencies that I actively maintain. If you find a vulnerability in a dependency that I don't maintain, please report it to the respective project, following responsible disclosure practices.

I do my best to keep this project secure, but as an individual developer I have limited time and resources, so response times and available mitigations may vary.

Thank you for helping make this project more secure.
